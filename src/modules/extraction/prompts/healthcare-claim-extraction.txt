=== OCR INPUT YOU RECEIVE ===

The user message contains two OCR sections (same content, two passes):

1) OCR TEXT — pages as "--- Page N ---", visual rows (wide column gaps shown as " || "), then [TABLE] rows.
   - Each " || " separator means the text before and after are in separate columns on the same visual row.
   - Use " || " to correctly pair labels (left column) with values (right column).

2) OCR TEXT REPEATED — plain fallback of the same pages, used when section 1 is truncated.
   - Cross-reference with section 1 if a page appears cut off.

Common Indonesian / English invoice labels:
Nominal, Jumlah, Jumlah Tagihan, Total, Grand Total, Total Bayar, Sub Total, Amount Due, Total Due, Biaya, Tagihan.

LABEL + VALUE LAYOUT (critical):

A) Same OCR row: "Nominal : 600000" or "Jumlah Tagihan : Rp 1.200.000,-"
   → value is the number/currency part AFTER the colon (or on the same row).

B) Stacked rows (very common): row 1 = label only ("Nominal", "Nama", "Jumlah"), row 2 = value on the next line.
   → You MUST read the NEXT row as the value. Never use the label row alone as value.

C) Table cells: amount may be in the rightmost column on the same table row as the label.

D) Multi-column forms (same visual row, two or more fields):
   Example: "Nama Pasien:          No Pegawai:" on one row with empty or filled values below each column.
   → Each column is a SEPARATE field. NEVER use the right column's label ("No Pegawai") as the value for the left column ("Nama Pasien").
   → If a column has only a printed label and no filled value (blank after ":" or on the next line in that column), use "not_found" for that field.
   → Match values to labels by horizontal position (same column), not by reading left-to-right across the whole row as one label:value pair.

VALUE RULES (all fields):

- value MUST be copied from OCR (digits, names, dates). Never use punctuation-only tokens as value.
- FORBIDDEN as value: ".", ",", ":", "-", "—", "/", "No", "No.", empty string, or any printed LABEL WORD from the same field (never use part of the label as the value).
- Compound labels are ONE label: "Nama Pasien", "Jumlah Tagihan", "Grand Total", "Tanggal Lahir" — do not split them into label + value on the same line.
- Stacked layout: row 1 = label only, row 2 = value on the NEXT line. If row 2 is missing or unreadable → "not_found".
- FORBIDDEN label tokens (never use as value): Nama, Pasien, Patient, Nominal, Jumlah, Total, Tagihan, Bayar, Tanggal, Tgl, Lahir, Masuk, Keluar, Polis, Klaim, Diagnosis, ICD.
- If you cannot find a real value in OCR, use "not_found" with confidence 0.

POST-PROCESSING (automatic):

Every field you return is verified against the OCR corpus. Values not found in OCR (including source_text) are rejected and replaced with "not_found". Pre-extracted hints and layout pairs override invalid LLM guesses. Do not guess — only output values you can quote from OCR.

MONETARY FIELDS (billing.total_amount_read, billing.tax_amount, billing.total_amount_calculated, items[].amount):

- value MUST contain at least one digit (0-9).
- Prefer the document GRAND TOTAL / final payable total, not intermediate "Subtotal" lines, unless no grand total exists.
- Keep Indonesian number formatting as in OCR: 1.200.000 / 1,200,000 / 600000 / 20.000,- / Rp 1.200.000
- total_amount_read: copy the printed invoice total (Nominal / Jumlah / Grand Total / Total Bayar).
- total_amount_calculated: sum of items[].amount only; do NOT copy total_amount_read here unless you computed the sum from line items.
- source_text: exact OCR line(s) that contain BOTH the label and the amount (or label line + amount line for stacked layout).

PATIENT NAME:

- Use explicit labels: Nama Pasien, Nama, Patient Name, Nama Tertanggung.
- "Nama Pasien" is ONE complete label (two words) — never use "Pasien" alone as patient.name.
- Do not use hospital name, doctor name, or address as patient.name.
- Stacked layout: row 1 = full label only ("Nama Pasien", "Nama", "Patient Name"); row 2 = the actual name on the next line.
- Same-row layout: "Nama Pasien : Budi Santoso" → value is after the colon, not part of the label.
- FORBIDDEN as patient.name value: "Nama", "Pasien", "Patient", "Name", "Tertanggung", or any single word from the label line.
- If only the printed label appears in OCR with no filled-in name on the next line or after ":", use "not_found".
